# Botwin Renovations LLC — Website

Production website for **Botwin Renovations LLC**, a renovation & remodeling company in Nashville, TN.

This is a static site generated by a small build script with no dependencies. Every page is plain HTML/CSS/JS, so it's fast, cheap to host and hard to break.

```
npm start          # build + local preview at http://localhost:4173 (form submissions work locally)
npm run build      # build to ./dist
npm test           # build + check every link, anchor, heading, meta tag, alt text and JSON-LD block
```

Requires Node 18+.

## Logo

The official "BR" logo is built in as vector artwork in `scripts/logo.js`. It was traced from `brand/botwin-logo-original.jpg` and matches it to within edge anti-aliasing. Every placement uses it: header, footer, menu, background marks, favicon and share image. If the logo ever changes, update `scripts/logo.js`, then run `node scripts/generate-raster.js` (with `npm start` running) to regenerate the favicons, PNG logo and share image.

## Editing content

All company facts live in **`site.config.js`**. Edit, rebuild and redeploy.

### Adding real project photos

1. Put originals in `assets/img/projects/` (e.g. `oak-st-kitchen-before.jpg`).
2. `npm i -D sharp && npm run images` creates AVIF/WebP at 640/1280/1920px.
3. In `site.config.js`, point the project at them and mark it real:
   ```js
   images: {
     before: '/assets/img/projects/oak-st-kitchen-before.jpg',
     process: '/assets/img/projects/oak-st-kitchen-process.jpg',
     after: '/assets/img/projects/oak-st-kitchen-after.jpg',
   },
   illustrative: false,
   location: 'East Nashville, TN',
   ```
   The build outputs a responsive `<picture>` element with AVIF → WebP fallbacks. For before/after sliders, shoot before and after from the **same spot** so they line up.

### Adding a review

Copy it word for word from Google/Facebook (with permission):
```js
reviews: [
  { name: 'Sarah M.', rating: 5, text: '…', project: 'Kitchen Remodel', source: 'Google', date: '2026-05-01' },
],
```
`Review`/`AggregateRating` schema is only emitted once real reviews exist.

## Contact form

The form collects name, phone, email, project address/city, project type, budget, desired start, message and up to 3 photos (8 MB total). It also adds a `submitted_at` timestamp and the page URL. It has loading, success and error states, inline validation and a honeypot for spam.

- **Netlify (default):** deploy to Netlify and the form works with no setup. Submissions appear under *Forms → consultation*. Turn on email notifications in *Site settings → Forms → Form notifications*.
- **Any other host:** set `form.provider = 'endpoint'` and `form.endpoint` to a Formspree/Basin/your-API URL. The form POSTs `multipart/form-data`.
- **Locally:** `npm start` saves submissions to `.submissions/submissions.jsonl` (photos alongside).

Without JavaScript the form still posts normally and lands on `/thank-you/`.

## Deploying

**Netlify:** connect the repo. `netlify.toml` sets the build (`node build.js`), publish dir (`dist`), cache and security headers. Any static host works; upload `dist/`.

After launch: submit `https://<domain>/sitemap.xml` in Google Search Console, and link the Google Business Profile in `social.google`.

## Design notes

- **Palette:** Jet `#050505`, Near-black `#111`, Charcoal `#1B1B1B`, Warm off-white `#F5F4F0`, White, Concrete `#A5A5A5`, Steel `#5C5D59`. No brand colour beyond black/white/grey; warmth comes from imagery only.
- **Type:** Archivo 900 (condensed via its width axis) for headlines, Manrope for body text, IBM Plex Mono for technical labels.
- **Logo-derived geometry:** the BR mark's angled cuts echoed as chamfered corners on images, buttons and the slider handle; its base bar echoed as thick "beam" dividers; oversized cropped mark in the hero, About, footer and mobile menu backgrounds.
- **Motion:** restrained. Scroll-driven hero wipe, mask reveals, word-by-word statement, timeline fill, cross-document view transitions. All disabled under `prefers-reduced-motion`.
- **Accessibility:** skip link, visible focus states, labelled fields with inline errors, keyboard-operable sliders/tabs/menu with a focus trap, WCAG AA contrast (axe-core clean).
